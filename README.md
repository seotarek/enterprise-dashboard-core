# Enterprise Dashboard Core 📊

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Next.js 15](https://img.shields.io/badge/Next.js-15-black.svg?logo=next.js)](https://nextjs.org/)
[![Tailwind CSS](https://img.shields.io/badge/Tailwind-CSS-38B2AC.svg?logo=tailwind-css)](https://tailwindcss.com/)

**A production-ready Next.js 15 and Tailwind CSS multi-tenant dashboard boilerplate featuring native Arabic (RTL) / English (LTR) bidirectional layout, role-based access control (RBAC), and enterprise telemetry.**

Developed by **Tarek Mohamed** ([@seotarek](https://github.com/seotarek))

---

## ✨ Features

- 🌐 **Native Bilingual RTL / LTR:** Out-of-the-box support for Arabic right-to-left and English interfaces.
- 🏢 **Multi-Tenant Architecture:** Tenant-scoped session state and organization contexts.
- ⚡ **Next.js 15 App Router:** Server Components for ultra-fast initial load times.
- 🎨 **Tailwind CSS & Lucide Icons:** Clean, accessible, and customizable design tokens.

---

## 🚀 Quickstart

```bash
git clone https://github.com/seotarek/enterprise-dashboard-core.git
cd enterprise-dashboard-core
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the dashboard.
